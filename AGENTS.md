# STREET LEGENDS — правила разработки

- Сохранять работоспособность проекта после каждого изменения.
- Не удалять работающие механики без причины.
- Использовать понятные имена; делить сложную логику на модули.
- Проверять импорт, GDScript и headless-тесты после изменений.
- Документировать важные технические решения в docs/architecture.md.
- Не добавлять лишние зависимости и тяжёлые эффекты без измерений.
- Использовать только собственные или явно лицензированные ассеты.
- Не изменять файлы вне проекта без разрешения пользователя.
- Не утверждать, что выполнены визуальные проверки или достигнуты 60 FPS, без измерений.
