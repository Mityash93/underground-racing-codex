# STREET LEGENDS — Уличные легенды

Первая играбельная версия оригинальной 3D аркадной гонки для Godot 4.
Ночное **Неоновое кольцо**, белый кроссовер в стиле **T-Roc 2022**, широкая замкнутая трасса **2 421,9 м**
и дуэль на два круга против независимого AI «Вектор» на красном спортивном седане. Базовая геометрия и звук двигателя процедурные;
дорога и отражения используют бесплатные CC0-ассеты Poly Haven.
В распространяемых ресурсах нет ассетов из NFS и внешних программных зависимостей.

## Запуск на Mac

1. Откройте Godot → **Import** → выберите `project.godot` из этой папки.
2. Дождитесь импорта и нажмите **F6** для открытой `scenes/main.tscn`
   или **F5 / ▶ Run Project** для всего проекта. На Mac может понадобиться Fn+F5.
3. В игре нажмите **НАЧАТЬ ЗАЕЗД** и дождитесь отсчёта 3–2–1.

Можно дважды щёлкнуть `run.command` в Finder или выполнить из папки проекта:

```sh
./run.command
```

Godot уже найден в `/Applications/Godot.app/Contents/MacOS/Godot`;
`/opt/homebrew/bin/godot` ссылается на него. Проверенная версия — **4.7.2 stable**.
Рекомендуется эта версия; проект использует Godot 4 и GDScript, без C#.
Исходный проект находится прямо в текущей папке репозитория, без вложенной копии.

## Соперник «Вектор»

Красный оригинальный седан с чертами спортивных BMW: низкий кузов,
сдвоенная решётка, четыре фары. Это процедурная модель, не точная модель BMW.
AI управляет отдельным физическим автомобилем: сам разгоняется, тормозит перед
поворотами, выбирает полосу для обгона и восстанавливается при застревании.
Обе машины стартуют после общего отсчёта. Побеждает тот, кто первым закончит
два круга через все чекпоинты. HUD показывает место и отрыв, миникарта — красную
метку соперника. Пауза, рестарт и меню действуют на обе машины.

Настройки AI — `scripts/cars/rival_driver.gd`, характеристики машины —
`resources/rival_tuning.tres`. Максимальная целевая скорость водителя — 165 км/ч;
динамического ускорения ради догоняния игрока нет.

## Управление

| Клавиши | Действие |
| --- | --- |
| W / ↑ | Газ |
| S / ↓ | Тормоз, затем задний ход |
| A / ←, D / → | Поворот |
| Space | Ручной тормоз / контролируемое скольжение |
| Shift + газ | Нитро при движении вперёд |
| R | Вернуться к последнему принятому чекпоинту, штраф +5 с |
| C | Ближняя / дальняя камера |
| M | Включить / выключить двигатель в звуке |
| N | Включить / выключить музыку |
| Esc | Пауза / продолжение |

Все действия используют **physical_keycode** и работают при русской раскладке.
Для заноса сбросьте газ перед поворотом, поверните и кратко нажмите Space;
затем отпустите ручник и скорректируйте направление.

## Новая трасса: «Неоновое кольцо»

Маршрут длиной **2,42 км**, шириной **24 м**, с 12 последовательными чекпоинтами:

- **Неоновый центр** — стартовая прямая 300 м и тоннель «Импульс» длиной 200 м.
- **Промзона «Искра»** — низкие фабрики, кран, трубы и грузовые контейнеры.
- **Связка «Волна»** — широкие S-повороты с предупреждениями за 100 и 50 м.
- **Северная набережная** — открытая вода, ограждение набережной и маяк.

Районы обозначены дорожными порталами; HUD показывает название текущего участка.
Миникарта масштабируется под всю трассу. В тоннеле достаточно места для камеры
и обгона. Старые рекорды короткой трассы сохранены в файле, но не сравниваются
с новой: версия маршрута изменена.

## Нитро, занос и личные рекорды

Удерживайте **Shift с газом** на прямой: полный запас даёт до **4,5 с** ускорения,
а предел скорости временно повышается на 30 км/ч. Камера плавно расширяет обзор.
Тормоз, ручник, задний ход и отсутствие контакта с дорогой блокируют нитро.
Отпустите Shift для зарядки: через 1,8 с после последнего расхода запас
восстанавливается на 10% в секунду.
Если опустошили баллон, отпустите Shift перед повторным использованием.
Рестарт даёт полный баллон; R сохраняет остаток. Запас виден под спидометром.

При заносе остаются следы задних шин и лёгкий дым. На каждую машину выделено
384 сегмента следа с затуханием за 8 с и 24 частицы дыма; объекты не копятся.

В меню доступны **лёгкий / средний / сложный** соперник. Уровень меняется до
заезда. Ориентиры скорости AI — 125 / 165 / 190 км/ч, с торможением в поворотах.

Рекорд полного заезда и лучший круг сохраняются в **local_data/records.cfg**
в папке проекта, отдельно по сложности и числу кругов. Меню показывает рекорд
выбранного режима, результат — новый рекорд. Незавершённый заезд не записывается.
Папка исключена из Git. Для текущего запуска из исходников нужен доступ на
запись в папку проекта; перенос сохранений в каталог экспортированной игры
остаётся задачей перед выпуском сборки. Файлы вне проекта не создаются системой рекордов.

## Музыка и русский интерфейс

Меню, HUD, подсказки, результаты и вывески переведены на русский.
Встроен оригинальный электронный трек **«Неоновый пульс»**: 132 BPM,
~58 секунд, зацикливание. Во встроенной композиции нет записей и мелодий NFS.

В главном меню и паузе есть блок **«Музыка»**: переключатель N, отдельная
громкость, кнопки **«Свой трек…»** и **«Встроенный трек»**.
Можно выбрать локальный **OGG, MP3 или WAV**. Файл не копируется в проект
и не отправляется в сеть. Выбор и громкость действуют до закрытия игры.
Личные файлы в `assets/audio/local/` исключены из Git; не включайте чужие записи
в распространяемую сборку без разрешения. M отдельно управляет двигателем.

Для автозапуска своей музыки поддерживается локальный
`assets/audio/local/default_music.cfg`: [пример настройки](assets/audio/local/README.md).
Эта папка исключена из Git и стандартного импорта/упаковки Godot.
Локально сохранённый трек запускается автоматически; на компьютере без этой
настройки остаётся оригинальная встроенная композиция.

Музыка тише в меню и на паузе. Собственный трек можно пересоздать командой
`python3 tools/generate_music.py`, внешние библиотеки не нужны.

## Что доступно

- Аркадный `RigidBody3D`: газ, тормоз, задний ход, сглаженный руль,
  сцепление, ручник, сопротивление, стабилизация, CCD и восстановление.
- Параметры в `resources/player_tuning.tres`, предел 225 км/ч.
- Камера за автомобилем с увеличением FOV на скорости и проверкой препятствий.
- Дорога шириной 24 м, ограждения, коллизии зданий, разметка, фонари,
  стартовая арка, неоновые полосы и вывески.
- Главное меню, HUD в км/ч, миникарта, текущий круг, таймер, пауза,
  перезапуск, возврат в меню и результаты.
- Отсчёт, 12 последовательных ворот, два круга, лучшее время круга.
- Фары и собственный синтезированный звук с условными переключениями передач.
- Визуальный крен/клевок кузова, плавное восстановление сцепления после заноса,
  более мягкий руль на скорости, объёмная проверка препятствий камеры.
- Скруглённый кузов с рамками окон, швами панелей, проекторными фарами,
  бамперами и подкрылками; тротуары, указатели поворотов, витрины и разные фасады.
- Белый T-Roc 2022: тёмная крыша, четыре двери, рейлинги, защитные накладки,
  отдельные нижние дневные огни и другой рисунок задних фонарей.
- Подключение отдельной полноценной сцены кузова/колёс через Inspector;
  [требования и инструкция](docs/real_vehicle_art.md). Текущий визуал остаётся
  упрощённой процедурной моделью, фотореалистичный ассет ещё не добавлен.
- Материал асфальта с картами цвета, рельефа и шероховатости, умеренными влажными
  участками; ночная HDRI в статической карте отражений. Источники/CC0 —
  [assets/THIRD_PARTY.md](assets/THIRD_PARTY.md).

## Проверки

Из корня проекта, после импорта:

```sh
godot --headless --path . --editor --import
godot --headless --path . --fixed-fps 60 --script tests/run_tests.gd
godot --headless --path . --fixed-fps 60 --script tests/test_wheels.gd
godot --headless --path . --fixed-fps 60 --script tests/test_media.gd
godot --headless --path . --fixed-fps 60 --script tests/test_vehicle_art.gd
godot --headless --path . --fixed-fps 60 --script tests/drive_lap.gd
```

Снимки настоящего рендера и короткий замер кадров:

```sh
godot --path . --resolution 1920x1080 --script tests/visual_capture.gd
```

Последняя команда открывает окно, программно выполняет короткий сценарий и закрывает его.
Снимки и отчёт пишутся в `tests/artifacts/`, логи с `--log-file` лучше задавать
абсолютным путём. Код возврата поведенческих тестов ненулевой при провале.
Скриншоты результатов этого сценария проверяют вёрстку на искусственно пройденных
воротах; полноценный физический заезд отдельно проверяет `drive_lap.gd`.

Результаты сессии 11.11.2026: **42 поведенческих + 17 колёсных + 14 медиа/UI + 8 подключения модели = 81, 0 провалов**;
0–100 км/ч **5,65 с**, предельная скорость **224,77 км/ч**;
проверочный водитель прошёл два физических круга без восстановлений.
Рендер и интерфейс осмотрены на снимках 1280×720 и 1920×1080.
Это не ручная проверка ощущений управления или прослушивание аудио.

## Графика и ограничения

Используется **Mobile / Metal** на macOS, MSAA 2×, одна направленная тень,
14 локальных источников света без теней (включая тоннель) и фары без теней. Нет SSR, тяжёлого GI,
volumetric fog, motion blur и полноэкранного bloom. Окно по умолчанию 1280×720,
интерфейс рассчитан на 1920×1080 и масштабируется через `canvas_items`.
Для другого разрешения: `./run.command --resolution 1920x1080`.

На M1 Pro короткий замер 180 кадров у стартовой решётки в 1920×1080 дал
средние **16,67 мс / 60,0 FPS**, P95 **22,24 мс** после добавления PBR-материалов.
Частота экрана не фиксировалась;
это узкий замер, а не сравнительный benchmark и не гарантия стабильных 60 FPS
на всей трассе или на всех экранах.

Пока нет трафика, гаража, сохранения настроек, настоящей подвески
и собранных экспортов. Windows-экспорт потребует официальных export templates
Godot и отдельной проверки рендера/управления; платформенных плагинов в коде нет.

## Структура

```text
project.godot           настройки, Input Map, главная сцена
AGENTS.md              правила дальнейшей разработки
run.command            запуск на macOS
scenes/main.tscn        композиция игры
scenes/cars/           сцена автомобиля
scenes/tracks/         сцена Neon District
scenes/ui/             интерфейс
scripts/cars/          физика, нитро, AI, параметры, синтез двигателя
scripts/effects/       следы шин и процедурный дым
scripts/camera/        камера сопровождения
scripts/race/          гонка, круги, чекпоинты
scripts/core/          композиция, генератор города, геометрия
scripts/ui/            меню, HUD, миникарта
resources/             настройки автомобиля
assets/                шейдер, происхождение и места для будущих ассетов
tools/                 генератор оригинальной музыки
tests/                 поведенческие, заезд, визуальный сценарий
docs/                  архитектура, план, фактический прогресс
```

Меню строится модулем `GameUI` внутри общей UI-сцены; `scenes/menu/`
оставлен для будущего выделения самостоятельной сцены меню.
См. [архитектуру](docs/architecture.md), [этапы](docs/roadmap.md)
и [фактические проверки и ограничения](docs/progress.md).
Результат поиска подробного T-Roc и ограничения скачивания —
[исследование моделей](docs/asset_research_2026-11-12.md).

Проверка AI и обгона неподвижной машины:

```sh
godot --headless --path . --fixed-fps 60 --script tests/test_rival.gd
```

Проверка нитро, следов, сложности и сохранения рекордов:

```sh
godot --headless --path . --fixed-fps 60 --script tests/test_race_features.gd
```

Для полного заезда AI на другом уровне добавьте к `test_rival.gd`
`-- --difficulty=0` (лёгкий), `1` (средний), `2` (сложный).

Проверка новой трассы (свободный проезд, коллизии, свет, миникарта):

```sh
godot --headless --path . --fixed-fps 60 --script tests/test_track.gd
```

Снимки районов и полный графический проверочный круг в 1080p:

```sh
godot --path . --resolution 1920x1080 --script tests/track_visual_capture.gd
```

Для одних снимков добавьте `-- --views-only`. Полный графический сценарий ведёт
игрока физическими командами без нитро, соперник припаркован; это не ручной заезд.
В измеренном круге этой сессии: **77,83 с**, среднее **9,36 мс / 106,9 FPS**,
P95 **19,82 мс**, 17 кадров дольше 33,3 мс из 8301. Замер сделан перед последней
регулировкой яркости материала воды. Он не гарантирует стабильные 60 FPS
в дуэли, на другом экране или при длинной игровой сессии.
