# STREET LEGENDS — Уличные легенды

Первая играбельная версия оригинальной 3D аркадной гонки для Godot 4.
Ночной **Neon District**, спортивное купе, широкая замкнутая трасса **1 343,9 м**
и solo time attack на два круга. Модели, материалы и звук создаются процедурно.
Заимствованных ассетов NFS и внешних зависимостей нет.

## Запуск на Mac

1. Откройте Godot → **Import** → выберите `project.godot` из этой папки.
2. Дождитесь импорта и нажмите **F6** для открытой `scenes/main.tscn`
   или **F5 / ▶ Run Project** для всего проекта. На Mac может понадобиться Fn+F5.
3. В игре нажмите **НАЧАТЬ ЗАЕЗД** и дождитесь отсчёта 3–2–1.

Можно дважды щёлкнуть `run.command` в Finder или выполнить из папки проекта:

```sh
./run.command
```

Godot уже найден в `/Applications/Godot.app/Contents/MacOS/Godot`;
`/opt/homebrew/bin/godot` ссылается на него. Проверенная версия — **4.7.2 stable**.
Рекомендуется эта версия; проект использует Godot 4 и GDScript, без C#.
Исходный проект находится прямо в текущей папке репозитория, без вложенной копии.

## Управление

| Клавиши | Действие |
| --- | --- |
| W / ↑ | Газ |
| S / ↓ | Тормоз, затем задний ход |
| A / ←, D / → | Поворот |
| Space | Ручной тормоз / контролируемое скольжение |
| R | Вернуться к последнему принятому чекпоинту, штраф +5 с |
| C | Ближняя / дальняя камера |
| M | Включить / выключить двигатель в звуке |
| N | Включить / выключить музыку |
| Esc | Пауза / продолжение |

Все действия используют **physical_keycode** и работают при русской раскладке.
Для заноса сбросьте газ перед поворотом, поверните и кратко нажмите Space;
затем отпустите ручник и скорректируйте направление.

## Музыка и русский интерфейс

Меню, HUD, подсказки, результаты и вывески переведены на русский.
Встроен оригинальный электронный трек **«Неоновый пульс»**: 132 BPM,
~58 секунд, зацикливание. Записи и мелодии NFS не использованы.

В главном меню и паузе есть блок **«Музыка»**: переключатель N, отдельная
громкость, кнопки **«Свой трек…»** и **«Встроенный трек»**.
Можно выбрать локальный **OGG, MP3 или WAV**. Файл не копируется в проект
и не отправляется в сеть. Выбор и громкость действуют до закрытия игры.
Личные файлы в `assets/audio/local/` исключены из Git; не включайте чужие записи
в распространяемую сборку без разрешения. M отдельно управляет двигателем.

Музыка тише в меню и на паузе. Собственный трек можно пересоздать командой
`python3 tools/generate_music.py`, внешние библиотеки не нужны.

## Что доступно

- Аркадный `RigidBody3D`: газ, тормоз, задний ход, сглаженный руль,
  сцепление, ручник, сопротивление, стабилизация, CCD и восстановление.
- Параметры в `resources/player_tuning.tres`, предел 225 км/ч.
- Камера за автомобилем с увеличением FOV на скорости и проверкой препятствий.
- Дорога шириной 24 м, ограждения, коллизии зданий, разметка, фонари,
  стартовая арка, неоновые полосы и вывески.
- Главное меню, HUD в км/ч, миникарта, текущий круг, таймер, пауза,
  перезапуск, возврат в меню и результаты.
- Отсчёт, 12 последовательных ворот, два круга, лучшее время круга.
- Фары и собственный синтезированный звук с условными переключениями передач.
- Визуальный крен/клевок кузова, плавное восстановление сцепления после заноса,
  более мягкий руль на скорости, объёмная проверка препятствий камеры.
- Скруглённый кузов с рамками окон, швами панелей, проекторными фарами,
  бамперами и подкрылками; тротуары, указатели поворотов, витрины и разные фасады.

## Проверки

Из корня проекта, после импорта:

```sh
godot --headless --path . --editor --import
godot --headless --path . --fixed-fps 60 --script tests/run_tests.gd
godot --headless --path . --fixed-fps 60 --script tests/test_wheels.gd
godot --headless --path . --fixed-fps 60 --script tests/test_media.gd
godot --headless --path . --fixed-fps 60 --script tests/drive_lap.gd
```

Снимки настоящего рендера и короткий замер кадров:

```sh
godot --path . --resolution 1920x1080 --script tests/visual_capture.gd
```

Последняя команда открывает окно, программно выполняет короткий сценарий и закрывает его.
Снимки и отчёт пишутся в `tests/artifacts/`, логи с `--log-file` лучше задавать
абсолютным путём. Код возврата поведенческих тестов ненулевой при провале.
Скриншоты результатов этого сценария проверяют вёрстку на искусственно пройденных
воротах; полноценный физический заезд отдельно проверяет `drive_lap.gd`.

Результаты сессии 11.11.2026: **42 поведенческих + 17 колёсных + 14 музыкальных/интерфейсных проверок = 73, 0 провалов**;
0–100 км/ч **5,65 с**, предельная скорость **224,77 км/ч**;
проверочный водитель прошёл два физических круга без восстановлений.
Рендер и интерфейс осмотрены на снимках 1280×720 и 1920×1080.
Это не ручная проверка ощущений управления или прослушивание аудио.

## Графика и ограничения

Используется **Mobile / Metal** на macOS, MSAA 2×, одна направленная тень,
11 локальных фонарей без теней и фара без тени. Нет SSR, тяжёлого GI,
volumetric fog, motion blur и полноэкранного bloom. Окно по умолчанию 1280×720,
интерфейс рассчитан на 1920×1080 и масштабируется через `canvas_items`.
Для другого разрешения: `./run.command --resolution 1920x1080`.

На M1 Pro короткий замер 180 кадров у стартовой решётки в 1920×1080 дал
средние **16,66 мс / 60,0 FPS**, P95 **21,41 мс**. Это узкий замер с VSync,
а не гарантия стабильных 60 FPS на всей трассе или на всех экранах.

Пока нет соперников, трафика, гаража, сохранений, следов шин, настоящей подвески
и собранных экспортов. Windows-экспорт потребует официальных export templates
Godot и отдельной проверки рендера/управления; платформенных плагинов в коде нет.

## Структура

```text
project.godot           настройки, Input Map, главная сцена
AGENTS.md              правила дальнейшей разработки
run.command            запуск на macOS
scenes/main.tscn        композиция игры
scenes/cars/           сцена автомобиля
scenes/tracks/         сцена Neon District
scenes/ui/             интерфейс
scripts/cars/          физика, параметры, синтез двигателя
scripts/camera/        камера сопровождения
scripts/race/          гонка, круги, чекпоинты
scripts/core/          композиция, генератор города, геометрия
scripts/ui/            меню, HUD, миникарта
resources/             настройки автомобиля
assets/                шейдер, происхождение и места для будущих ассетов
tools/                 генератор оригинальной музыки
tests/                 поведенческие, заезд, визуальный сценарий
docs/                  архитектура, план, фактический прогресс
```

Меню строится модулем `GameUI` внутри общей UI-сцены; `scenes/menu/`
оставлен для будущего выделения самостоятельной сцены меню.
См. [архитектуру](docs/architecture.md), [этапы](docs/roadmap.md)
и [фактические проверки и ограничения](docs/progress.md).
