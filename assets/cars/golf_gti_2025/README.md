# Golf GTI 2025 — локальная модель соперника

[Volkswagen Golf GTI (2025), geyges](https://sketchfab.com/3d-models/volkswagen-golf-gti-2025-84fe6c2b9feb4c8a854d16f3daf33eab).
Пользователь скачал бесплатный glTF ZIP через Sketchfab. Авторский license.txt
сохранён без изменений: **SKETCHFAB Standard / Free Standard**, не CC BY.
Архив и подготовленная геометрия исключены из Git: используются внутри игры,
не распространяются отдельным ассетом.

## Восстановление на другом компьютере

1. Скачать glTF ZIP с карточки автора после входа в Sketchfab.
2. Положить сюда volkswagen_golf_gti_2025.zip.
3. Из корня проекта выполнить `python3 tools/prepare_golf_gti_2025.py`.
4. Открыть Godot и дождаться импорта. При запуске соперник станет Golf.

Без файлов prepared/ игра запускается с процедурным красным соперником.
Скрипт использует стандартную библиотеку Python и ничего не устанавливает.
Рассчитан на выбранный архив; другая модель потребует адаптации.

## Подготовка

Первые ключи анимаций фиксируют закрытые двери, багажник и люк; анимации
и airbags убраны. В кузове нет колёс или дублирующих тормозов. Правое переднее
колесо используется на четырёх креплениях, левое разворачивается наружу.
Радиус 0,328 м; передняя/задняя полуколея 0,765/0,748 м. Точная калибровка —
в calibration.json и resources/golf_gti_2025_art.tres. Суппорты не вращаются
с колёсами; передние поворачивают вместе с рулём. Для задних тормозов пока
используется передняя сборка. Два красных вкладыша реагируют на торможение.

Несовместимые UV-наборы AO и metallic/roughness отключены; остаются базовые
коэффициенты материалов. Исходные текстуры сохранены. Исходник содержит
371 827 граней по Sketchfab; LOD/decimation пока не выполнены.
source.json фиксирует источник, лицензию и SHA-256 полученного архива.
