# Audi R8 игрока

This work is based on "Audi R8" (https://sketchfab.com/3d-models/audi-r8-e17e438f076f4427a58d93aa779edaed)
by wallon (https://sketchfab.com/realwallon) licensed under CC-BY-4.0
(https://creativecommons.org/licenses/by/4.0/).

Оригинальный license.txt сохранён. Пользователь предоставил официальный ZIP.
В игре указаны автор и ссылки. Модель адаптирована: преобразования запечены,
длина приведена к 4,5 м, перед направлен по -Z, части объединены по материалам.
Парные колёса разделены; переднее правое колесо повторяется на четырёх креплениях,
левые разворачиваются наружу. Суппорты отделены от качения, передняя сборка
используется и сзади. Из геометрии колёс и суппортов убраны исходные поворот и развал;
плоскости дисков перпендикулярны оси качения X. Ширина шин исходная. Медная окраска, текстуры и световая геометрия сохранены;
шероховатость ограничена снизу 0,1, красный свет реагирует на торможение.

## Повторный импорт

Положить сюда audi_r8.zip, затем из корня выполнить:

```sh
python3 tools/prepare_audi_r8.py
```

Открыть Godot и дождаться импорта. Python использует только стандартную библиотеку.
ZIP и prepared/ исключены из Git, чтобы не дублировать крупные ассеты. Лицензия
CC BY допускает распространение с атрибуцией; исключение здесь — организация
репозитория. Без файлов автоматически используется белый процедурный T-Roc.
Калибровка — calibration.json и resources/audi_r8_art.tres. LOD пока нет.
