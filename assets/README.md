# Происхождение ассетов

Модель автомобиля, колёса, здания, фонари, дорога, разметка, вывески и материалы
создаются кодом проекта. Шейдер асфальта находится в materials/asphalt.gdshader.
Скруглённый кузов и детали купе строятся в scripts/cars/coupe_body.gd,
тротуары и указатели — в scripts/core/city_details.gd.
Звук двигателя синтезируется в scripts/cars/engine_audio.gd из гармоник синуса.

Внешние модели, записи звука, музыка, бренды автомобилей и материалы NFS не используются.
Каталоги cars/, tracks/, textures/ и audio/ зарезервированы под будущие ассеты
с проверенным происхождением. Сейчас они не нужны для запуска.
