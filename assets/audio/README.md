# Музыка

`neon_pulse.wav` — оригинальная композиция «Неоновый пульс»: 132 BPM,
32 такта, ~58,18 секунды с зацикливанием. Электронный бас, синтезаторные партии,
синтезированные ударные. Сэмплы, мелодии и записи из NFS не используются.

Исходный генератор: `tools/generate_music.py`, только стандартная библиотека Python.
Повторная генерация: `python3 tools/generate_music.py` из папки проекта.

Громкость и выбор локального файла доступны в меню и паузе. N включает/выключает
музыку; M отдельно управляет двигателем. Личные записи не входят в репозиторий.
