# Личная музыка

В игре откройте блок «Музыка» в главном меню или паузе → «Свой трек…».
Поддерживаются OGG, MP3 и WAV. Файл проигрывается с выбранного пути,
не копируется и не отправляется в сеть. Выбор действует до закрытия игры.

Если храните личную музыку в этой папке, она исключена из Git через .gitignore.
Не добавляйте чужие записи в распространяемый проект без разрешения правообладателя.

## Автоматически при запуске

Можно хранить локальный файл `startup.mp3` и настройку `default_music.cfg`:

```ini
[music]
path="res://assets/audio/local/startup.mp3"
title="Мой трек"
```

MusicManager читает настройку при запуске. Если её или аудиофайла нет,
остаётся встроенная композиция. «Встроенный трек» переключает музыку в текущем
запуске; при следующем старте локальная настройка снова применяется.
MP3 и CFG не включаются в Git. `.gdignore` также исключает личную папку
из импорта и стандартной упаковки ресурсов Godot; локальная загрузка использует
AudioStreamMP3.load_from_file(), поэтому в исходном проекте музыка работает.
